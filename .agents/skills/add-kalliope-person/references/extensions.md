# Bibliografi og tidslinje

Læs `docs/xml-info-format.md` og relevante dele af `schemas/kalliopework.rng`.
Brug aktuelle sammenlignelige filer og deres rendering som formatreference:
`fdirs/reenberg/bibliography-primary.xml`,
`fdirs/reenberg/bibliography-secondary.xml` og personens eventuelle `events.xml`.
Undersøg `tools/build-static/poets.js` og tidslinjebyggeren før nye konstruktioner.

Skeln mellem personens egne udgivelser og litteratur om personen. Dokumentér
udgave, år, bind og kilder; undgå at udgive et udvalg som fuldstændig bibliografi.
Tidslinjebegivenheder skal være kildebelagte; opfind ikke præcise datoer ud fra år.
Bevar eksisterende poster og brug kun understøttet markup. Kør `make test`.

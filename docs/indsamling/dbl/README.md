# Dansk Biografisk Leksikon

Kilden er endnu ikke høstet. Mappen er reserveret til et reproducerbart
snapshot og det tilhørende manifest.

## Planlagt hentning

Undersøg først Lex’ stabile opslag, søgeflade og eventuelle kategorier eller
sitemaps. Gem derefter kildens relevante index, rå opslag og et manifest med
URL, hentetidspunkt og brugsbegrænsninger. Høstning må ikke begynde, før
adgangs- og genbrugsvilkårene er dokumenteret.

## Forventede felter og problemer

Opslag forventes at kunne give stabil URL, navn, livsdata og biografisk belæg.
Lex’ søgeflade, kategorier, HTML-struktur og genbrugsvilkår skal afklares før
massehøst. Et eventuelt Wikidata-id skal bevares som berigelse, ikke som
erstatning for kildeobservationen.

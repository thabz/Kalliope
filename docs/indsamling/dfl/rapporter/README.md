# DFL-rapporter

Rapporter i denne mappe er genererede analyser af DFL-snapshottene i den
overordnede DFL-mappe.

- `work-audit.md`: titel- og værkposter
- `author-audit.md`: unikke DFL-forfatterobservationer
- `author-resolution.md`: foreløbig identitetsafklaring
- `manual-review-queue.md`: senere prioriteringskø, ikke komplet kandidatregister

Rapporterne må slettes og genskabes fra snapshots. De må ikke bruges som
erstatning for `authors.json`, `works.json` eller den rå HTML-cache.

# Dansk Kvindebiografisk Leksikon

Kilden er endnu ikke høstet. Mappen er reserveret til et reproducerbart
snapshot og det tilhørende manifest.

## Planlagt hentning

Undersøg Lex’ kategori eller forfatterindex for Dansk Kvindebiografisk
Leksikon. Gem index, rå opslag og manifest med stabile URL’er, hentetidspunkt,
felter og brugsbegrænsninger. Kilden skal behandles som egne observationer,
før den sammenholdes med andre kilder.

## Forventede felter og problemer

Opslag forventes at kunne give stabil URL, navn, livsdata og biografisk belæg.
Kilden har et andet udvalg end DFL og DBL; kategorien “Forfattere” bør derfor
behandles som en afgrænset kildemængde og ikke som komplet dækning.

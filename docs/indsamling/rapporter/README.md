# Tværgående rapporter

Rapporter i denne mappe sammenstiller observationer fra flere kilder. De er
genererede arbejdsresultater, ikke et selvstændigt kildelag.

`wikidata-overlap.md` er den Wikidata-specifikke overlaprapport. Den skelner
mellem stærke id-match, mulige navnematch, konflikter og manglende kilder.
